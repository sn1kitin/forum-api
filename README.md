# Forum API

Schoolopdracht module 15 (Xperience Back-end Development).
Een REST API voor een forum, gemaakt in vanilla PHP zonder framework.

## Installatie

1. Zet het project in `C:\xampp\htdocs\forum-api`
2. Importeer `database/forum_api.sql` in phpMyAdmin, dit maakt de database `forum_api_db` aan
3. Run `composer dump-autoload`
4. Open `http://localhost/forum-api/`
